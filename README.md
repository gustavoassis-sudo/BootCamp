# Gustavo Assis — Projeto Bootcamp Claude Code

> Bootcamp Claude Code — Moon Ventures (2026)

## Sobre o projeto

- **Problema**: O processo de aprovação de influenciadores na Moon é 100% manual. O time de marketing avalia cada influenciador individualmente, sem padronização, sem histórico organizado e sem automação — consumindo horas por campanha.
- **Solução proposta**: Plataforma web que analisa automaticamente o fit de influenciadores com as marcas da Moon (Minimal Club e Hoomy) usando Claude, retornando aprovado/reprovado/revisar com justificativa e mantendo pipeline organizado por campanha.
- **Slug**: `influencer-approval`
